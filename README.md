# Light Them Up

A phone-first street-lamp game in plain HTML, CSS and JavaScript (no build step): `index.html`, `styles.css`, `i18n.js` (translations), `borca-map.js` (map data) and `game.js`. You inherit a dark neighbourhood, place and maintain street lamps, keep residents happy and chase off hooligans and thieves. Play in an invented quarter, in real Borča, or in any town in the world (map data from OpenStreetMap).

Play: open `index.html` in a browser, or use the GitHub Pages link of this repository.

Map data © OpenStreetMap contributors (ODbL).
